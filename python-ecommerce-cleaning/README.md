# Python Data Cleaning – E-commerce Orders

This project uses **Python (Pandas)** to clean and prepare a messy e-commerce dataset for analysis.  
The dataset contains ~300 clothing-brand orders with missing values, formatting errors, duplicates, and inconsistent fields.

---

## Skills Demonstrated
- Data Cleaning & Transformation with **Pandas**
- Handling Missing and Duplicate Records
- Fixing Invalid Data (negative quantities, bad dates)
- String Standardization & Categorical Cleaning
- Calculating Derived Columns (Delivery Days, Recalculated Totals)
- Exporting Clean Datasets for Analysis

---

## Project Files
| File | Description |
|------|-------------|
| `ecommerce_data.csv` | Raw messy dataset |
| `ecommerce_cleaning.py` | Python script for data cleaning |
| `ecommerce_data_cleaned.csv` | Cleaned dataset generated by script |

---

## Cleaning Steps
1. **Handled duplicates & nulls** in key columns  
2. **Replaced invalid quantities** and coerced data types  
3. **Converted date fields** to proper `datetime` format  
4. Added **`Delivery_Days`** column to calculate shipping time  
5. **Standardized text fields** (casing, whitespace, “Unknown” values)  
6. **Recalculated totals** and validated with new columns  
7. Exported clean dataset to `ecommerce_data_cleaned.csv`

---

## Summary Insights
- 5% of records had missing product or customer names  
- ~3% contained invalid quantities (negative or zero)  
- Dates were stored in mixed formats; all standardized  
- Several states labeled “Unknown” were fixed or removed  
- Recalculated totals exposed minor rounding issues
